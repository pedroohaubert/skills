# Motion

Pick the one guide your task matches. Each lives at `emil/<name>/GUIDE.md`.

| Task | Guide |
|---|---|
| Build one animation or transition from scratch | `animate` |
| Several elements moving together: stagger, sequence, hero entrance, morph | `choreograph` |
| Anything dragged, swiped, flung, or held: drawers, sheets, reorder | `gestures` |
| An animation is janky or drops frames; choosing which property to animate | `animation-performance` |
| Review the motion in a diff or one component | `review-animations` |
| Audit a whole codebase's motion and plan the fixes | `improve-animations` |
| Find places that should animate and do not | `find-animation-opportunities` |
| The app feels slow or over-animated: remove motion | `remove-animations` |
| Name an effect the user describes vaguely | `animation-vocabulary` |
| Sonner toasts: setup, API, troubleshooting | `ask-sonner` |

For a small interaction detail (hold to confirm, text swap button, tab indicator, edge-aware tooltip), check the studies at https://microinteractions.dev/llms.txt before building it from zero.

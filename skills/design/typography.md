# Typography

The app's existing type scale and fonts come first. These numbers are for when you set or fix them.

## Body text (Butterick, Practical Typography)

| Property | Range |
|---|---|
| Size on the web | 15–25 px |
| Line height | 1.2–1.45 |
| Line length | 45–90 characters |
| Letterspacing on all caps and small caps | 5–12% |
| Paragraph separation | space between paragraphs or a first-line indent, one of the two |

Use curly quotes and real dashes in interface copy.

## Choosing a UI font (Yep! Type)

A UI font needs cap-centered vertical metrics and a tall x-height, about 75% of cap height; otherwise labels sit low inside buttons and inputs. Inter and San Francisco are the reference at 75%.

When the brief wants something other than Inter, candidates that meet the criterion: Innovator Grotesk, Universal Sans, Plain, SwissNow, Muoto, Aktiv Grotesk, Akkurat, Basier, CoFo Sans, Unifora. Check each one's licence before shipping it.

Full reference: https://practicaltypography.com/
